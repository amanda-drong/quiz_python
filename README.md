
# Quiz de Python

Um quiz interativo desenvolvido em Python com a biblioteca Tkinter, com o objetivo de praticar conceitos básicos de programação por meio de perguntas e respostas.

## Funcionalidades

- Exibição de perguntas com três alternativas.
- Verificação automática das respostas.
- Feedback indicando se a resposta está correta ou incorreta.
- Contagem de pontos conforme os acertos.
- Exibição do resultado final ao concluir o quiz.
- Opção para reiniciar o jogo e tentar novamente.

## Tecnologias utilizadas

- **Python:** linguagem utilizada no desenvolvimento.
- **Tkinter:** biblioteca utilizada para criar a interface gráfica.

## Requisitos

- Python 3 instalado.
- Tkinter disponível na instalação do Python.

## Como executar o projeto

1. Clone este repositório ou baixe os arquivos do projeto.
2. Abra a pasta do projeto no terminal.
3. Execute o comando:

   ```bash
   python main.py
   ```

4. A janela do quiz será aberta. Selecione uma alternativa para responder a cada pergunta.

## Como funciona

As perguntas e alternativas são organizadas em uma lista de dicionários. Cada pergunta possui suas alternativas e o índice da resposta correta.

O programa compara a alternativa selecionada com a resposta correta, atualiza a pontuação e avança para a próxima pergunta. Ao final, exibe a quantidade de acertos e permite iniciar uma nova partida.
